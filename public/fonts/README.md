Inter and Cormorant Garamond font files are the exact woff2 files emitted by the successful production build of commit ce32e8654d5fc0cfc77f7778ee764df29145c721, originally fetched by next/font/google. They are bundled locally to avoid the Google font URL parsing failure during hosted builds. The original unicode ranges, weights, display policy and fallback metrics are preserved in src/app/fonts.css. See the accompanying SIL Open Font Licenses, retrieved from google/fonts on 14 November 2026.
